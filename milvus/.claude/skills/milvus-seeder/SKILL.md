# milvus-seeder 项目需要实现的功能介绍
1. 数据导入
从对象存储中读取数据，并且将数据写入到milvus 数据库中。


2. 写入qps 测试
测试数据在不同批次下的写入qps 情况。


3. milvus schema

pk ,主键, int64
value, float vector, dim=1024
scalar varchar(8192)
doc_id, int64
sparse_vector 由scalar 字段bm25函数生成的稀疏向量

再内存里面的实体类：MilvusEntity


以下需求细节：
1. Milvus 版本 - 使用 Milvus SDK v2 
2. 写入方式 - 仅 insert
3. 并发策略 - 需要支持多线程并发写入，统计总的qps
4. 测试数据规模 - 预期单次导入数据量为 1000 条数据，需要每5分钟汇报下写入的 qps 情况,包括总的写入速率和每个线程的写入速率。

2. 核心流程

阶段1: 文件发现                                                                                                                                                                                                                                                                                          
└── listObjects(bucket, prefix)                                                                                                                                                                                                                                                                       
└── 获取所有 parquet 文件列表 (10-250个文件)

阶段2: 并行读取 (生产者线程池)                                                                                                                                                                                                                                                                           
└── 每个文件一个 Reader 线程                                                                                                                                                                                                                                                                          
└── 流式解析 parquet（不一次性加载整个文件）                                                                                                                                                                                                                                                          
└── 每读取 batchSize 条数据                                                                                                                                                                                                                                                                           
└── put 到队列（队列满时阻塞等待）

阶段3: 并发写入 (消费者线程池)                                                                                                                                                                                                                                                                           
└── poll(1秒超时)                                                                                                                                                                                                                                                                                     
└── 获取批次数据                                                                                                                                                                                                                                                                                      
└── 调用 MilvusClient.insert()                                                                                                                                                                                                                                                                        
└── 可重试错误：指数退避重试3次                                                                                                                                                                                                                                                                       
└── 不可重试错误：ERROR日志，跳过该批次

阶段4: 优雅关闭                                                                                                                                                                                                                                                                                          
├── 所有 Reader 完成 → readingFiles = 0                                                                                                                                                                                                                                                               
├── 队列为空                                                                                                                                                                                                                                                                                          
└── Writer 检测到结束条件后退出

阶段5: 统计汇报                                                                                                                                                                                                                                                                                          
└── 每5分钟输出 QPS 统计                                                                                                                                                                                                                                                                              
└── 最终汇总报告

4. 写入重试策略                                                                                                                                                                                                                                                                                          
   ┌───────────────┬────────────────────────────────────────────────────────────────────┬────────────────────────┐                                                                                                                                                                                          
   │   错误类型    │                                示例                                │          处理          │                                                                                                                                                                                          
   ├───────────────┼────────────────────────────────────────────────────────────────────┼────────────────────────┤                                                                                                                                                                                          
   │ 可重试（3次） │ SocketTimeoutException, ConnectException, "unavailable", "timeout" │ 指数退避：1s → 2s → 4s │                                                                                                                                                                                          
   ├───────────────┼────────────────────────────────────────────────────────────────────┼────────────────────────┤                                                                                                                                                                                          
   │ 不可重试      │ 数据格式错误、权限不足、磁盘满                                     │ ERROR 日志，跳过该批次 │                                                                                                                                                                                          
   └───────────────┴────────────────────────────────────────────────────────────────────┴────────────────────────┘                                                                                                                                                                                          
   // 重试逻辑                                                                                                                                                                                                                                                                                              
   for (int retry = 0; retry < 3; retry++) {                                                                                                                                                                                                                                                                
   try {                                                                                                                                                                                                                                                                                                
   client.insert(batch);                                                                                                                                                                                                                                                                            
   stats.addSuccess(count);                                                                                                                                                                                                                                                                         
   return;  // 成功                                                                                                                                                                                                                                                                                 
   } catch (Exception e) {                                                                                                                                                                                                                                                                              
   if (isRetryable(e) && retry < 2) {                                                                                                                                                                                                                                                               
   Thread.sleep(1000 * (retry + 1));  // 1s, 2s, 4s                                                                                                                                                                                                                                             
   } else {                                                                                                                                                                                                                                                                                         
   log.error("写入失败: {}", e.getMessage());                                                                                                                                                                                                                                                   
   stats.addFail(batch.size());                                                                                                                                                                                                                                                                 
   return;  // 放弃                                                                                                                                                                                                                                                                             
   }                                                                                                                                                                                                                                                                                                
   }                                                                                                                                                                                                                                                                                                    
   }

9. 启动示例

public static void main(String[] args) {                                                                                                                                                                                                                                                                 
// 配置                                                                                                                                                                                                                                                                                              
BatchConfig batchConfig = new BatchConfig()                                                                                                                                                                                                                                                          
.setQueueCapacity(200000)      // 20万条队列                                                                                                                                                                                                                                                     
.setBatchSize(500)             // 每批500条

          .setHost("milvus-server")                                                                                                                                                                                                                                                                        
          .setPort(19530)                                                                                                                                                                                                                                                                                  
          .setCollection("my_collection");                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                           
      // 执行导入                                                                                                                                                                                                                                                                                          
      SeederService service = new SeederService(s3Client, milvusConfig, batchConfig);                                                                                                                                                                                                                      
      service.importData("wgcn-tesr", "test/");                                                                                                                                                                                                                                                            
}
